# Telegram AI Video Bot V1.1

Railway-ready Telegram bot dengan OpenAI, voice-over, subtitle, FFmpeg, dan video 9:16.

Railway Variables:
BOT_TOKEN=token dari @BotFather
OPENAI_API_KEY=API key OpenAI
OPENAI_MODEL=gpt-4.1-mini
OPENAI_VOICE=alloy

Jangan upload .env.

Setelah repository dihubungkan ke Railway, deploy. Tahap berikutnya dapat menambahkan visual AI per scene, musik, animasi, dan template video contoh.
